# Discoveries — 2026-06-21

## Investigate
- **Cascadeflow (lemony-ai/cascadeflow)**: Open-source (MIT) library embedding model cascading, speculative execution, policy gates (budget, compliance, quality validators), and per-step audit traces *inside* the agent loop. Works with LangChain, CrewAI, OpenAI Agents, etc. Avoids extra network hops/proxies. Why interesting: Practical solution to "agent tax" (cost, latency, observability) in multi-agent setups; validator layer is load-bearing. Link: https://github.com/lemony-ai/cascadeflow (X thread: https://x.com/DanKornas/status/2068250245612347681). Next step: Clone repo, review implementation, wire into a minimal test agent workflow and measure gains.

- **LTX Director 2.0**: Major open-source update to free AI video creation/editing tool inside ComfyUI. Adds full video support (prompt-based extend/trim/split/combine, keyframes, audio inpainting), IC-LoRA, Retake Mode, JSON timeline save/load, UI overhaul with snapping/hotkeys. Positioned as capable free alternative to closed tools after 1.5 months focused work. Why interesting: Real engineering depth in a practical creative domain. Link: https://x.com/WhatDreamsCost/status/2068425046750638332. Next step: Install in ComfyUI environment, test a short video generation + editing pipeline.

- **Model Council / Judge Pattern**: Parallel drafts from multiple cheaper/open models, then frontier model acts as judge to compare, resolve contradictions, fill gaps, and synthesize final output. OpenRouter benchmarks showed quality lift (e.g., 69/100 vs 65.3). Why interesting: Simple, low-overhead way to improve reasoning/cost for high-stakes tasks like architecture or research. Next step: Prototype a small council setup (e.g., 2-3 models + judge) on a reasoning benchmark.

- **Build-your-own AI Engineering Primitives Curriculum**: Emphasis on implementing core components from scratch at least once: prompt caching, structured output parsers (via Context-Free Grammars), MoE routing layers, KV cache paging, function calling routers, RAG/Graph RAG pipelines, etc. Why interesting: Fastest path to deep intuition and avoiding framework magic. Link: https://x.com/asmah2107/status/2068458354972991868. Next step: Choose one primitive (e.g., basic prompt cache or CFG parser), implement and test in isolation.

- **Obsidian LLM Second Brain / LLM Wiki**: Dump notes into Obsidian (Markdown), let LLM auto-link, summarize, organize into a queryable knowledge graph. Persistent context across sessions; model-agnostic. Recent enhancements via obsidian-skills and local search tools. Why interesting: Turns static notes into living, compounding system. Next step: Create small test vault, populate with content, experiment with LLM-driven linking/organization.
