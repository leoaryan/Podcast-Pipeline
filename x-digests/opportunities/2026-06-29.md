### 3. Review-Centric Agentic Coding Workflow & Self-Improvement Loops
**Who**: Multiple 2026 coding agent operators (https://x.com/i/status/2066595308629594363 and related).
**What they built**: Shift from generation to verification-first pipelines to combat AI slop.
**Step-by-step**:
- Default to Plan Mode for non-trivial tasks; re-plan on surprises.
- Use subagents to keep context clean.
- After every correction, update lessons.md and review at session start.
- Verification before done: tests, logs, diff checks; never mark complete without proof.
- Heterogeneous AI reviewers (2+ models/tools in parallel) for triage.
- Read test changes more carefully than code (agents rewrite assertions).
- Human owns merge/judgment on high blast-radius decisions; capture intent upfront (plans, decision logs).
**Tool stack**: Coding agents (Claude Code/Cursor) + test runners + multi-model reviewers + persistent lessons.md.
**Non-obvious insight**: Code output 4x but productivity gain only 10-12%; review must scale with blast radius, and agents hide bugs in tests — self-improvement via lessons.md turns one-off fixes into compounding advantage.
**What WE can apply**: Integrate into Hermes agent dev workflows + eval steps. Score: Novelty 4, Actionability 5, Depth 4, Relevance 5 (Total 18/20).
