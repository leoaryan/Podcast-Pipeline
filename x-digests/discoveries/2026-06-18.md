# Discoveries — 2026-06-18

## Investigate
- **Eve (Vercel)**: Open-source AI agent framework positioned as “Next.js but for agents.” Uses a simple folder-based structure (`agent.ts`, `instructions.md`, `tools/`, `skills/`, `sandbox/`, `schedules/`) with built-in support for durable workflows, sandboxed execution, human-in-the-loop, secure tool connections, tracing, and multi-channel deployment. Strong design philosophy focused on letting devs focus on logic. Link: https://vercel.com/blog/introducing-eve Suggested next: Read the announcement post in full and check for public repo/examples to understand the primitives.

- **Context Engineering Playbook** (@sairahul1): Practical guide to reliable long-running agents. Diagnoses common failure modes (context rot, lost-in-the-middle, poisoning) and provides four concrete strategies: Write (external persistence), Select (agentic RAG), Compress (summaries/trimming), Isolate (sub-agents + state schemas). Includes real outcomes like shipping 35k LOC Rust in one session. Link: https://x.com/i/status/2067171101978071501 Next step: Extract the 5-step agent turn pipeline and test one compaction technique in a small agent setup.

- **SkillOpt (Microsoft)**: Open-source framework for optimizing AI agent skills as ML artifacts. Iteratively improves skill documents via batch eval, LLM critique/edit, edit budget, and held-out validation. Claims better results than GEPO/EvoSkill/TextGrad. Technical thread with details. Suggested: Review the VentureBeat coverage + original thread for implementation patterns.

- **Loop Engineering** (@Whats_AI): Contrasts brittle fixed automation scripts with adaptive “loop engineering” where agents observe state, choose actions, evaluate results, and adapt/retry. Positions modern agent work as primarily writing resilient loops rather than linear pipelines. Link: https://x.com/Whats_AI/status/2066868695255728436 Next: Map a current brittle script to this loop pattern.
