# AI in Design & Creativity
**Date:** 2026-06-03

## Key Examples
- **Claude + MCP + Figma = Creative OS from @ekinciio** — Using Higgsfield MCP inside Claude, they describe the experience as a complete creative operating system. Claude acts as strategist, creative director, and project manager, generating storyboards, creative direction, and structured prompts. Produces high-quality images (via GPT Image 2), motion, and video — building entire company launches (visuals, marketing, product screens) in a single conversation. The MCP protocol is described as "USB-C for AI" — it standardizes how Claude connects to external tools. Source: x.com/ekinciio/status/2061852283336278173
- **Figma MCP architecture from @dishashah66** — A new discipline emerging: structuring Figma components specifically for AI consumption. Consistent property/variant naming, clear states and anatomy, predictable design tokens, well-defined component hierarchies. When Figma is a structured source of truth, Claude (via Figma MCP connector) can read it and reproduce designs with 95%+ accuracy in code. "Poor organization leads to AI guessing; clean architecture makes correct code the easiest path." Designers are now treating the Figma→AI handoff as information architecture rather than visual polish. Source: x.com/dishashah66/status/2061452939819094047
- **@MaryamMiradi's solo founder stack**: Claude with strict `claude.md` rules (naming conventions, never use sync in async nodes, retry patterns, max 300 lines), Plan Mode for architecture review before touching files, custom commands and hooks (auto-run tests, linting, mypy, pytest with self-fix on errors), git worktrees for parallel isolated sessions, and sub-agents with defined input/output schemas. This turns Claude from a suggestion machine into a reliable coding partner that ships real code. Source: x.com/MaryamMiradi/status/2061481455746969876

## Insights
- **Information architecture is the new design skill.** The gap between good and great AI-assisted design isn't model quality — it's how well your design system is structured for machine consumption. Designers who treat Figma as an API produce better AI output than those who treat it as a canvas.
- MCP is emerging as the connective tissue across the entire creative stack — Figma, Higgsfield, terminal, code execution, external APIs — all accessible through a single protocol. This turns Claude from a text generator into a universal creative runtime.
- The solo creator stack (Claude + MCP + Figma + Terminal) is collapsing the distance between concept and shipped creative work. What used to require a team (designer, developer, copywriter, video editor) can now be executed by one person in one conversation.
