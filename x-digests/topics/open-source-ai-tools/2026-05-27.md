# Open Source AI Tools & Models
**Date:** 2026-05-27

## Key Examples
- LLM Wiki: Fully local tool that turns PDFs and articles into a cross-linked markdown knowledge base.
- Presenton: Local presentation generator that exports to editable PPTX.
- map3d: Generates 3D city models from OpenStreetMap data in seconds.

## Insights
- Strongest momentum is in local-first tools that give users ownership of data.
- Focus is shifting from flashy new models to practical, ownable workflows.

## Notable Opinions
- Open-source tools are winning where data ownership and offline use matter most.
