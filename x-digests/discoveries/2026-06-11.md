# Discoveries — 2026-06-11

## Investigate
- **headless-three-webgpu**: CLI + library for running three.js + WebGPU (via Dawn) completely headless outside the browser. Supports rendering to PNG/WebP/MP4/GIF from CLI or agents; works on CPU too. Practical for server-side 3D, agentic workflows, CI. Real engineering focus on embedding 3D rendering. Link: https://github.com/juniorxsound/headless-three-webgpu (X: https://x.com/i/status/2064703181905432720). Next step: Install CLI, test with a .glb model, explore programmatic API.

- **late-interaction-kernels (LIK)**: Open-source fused Triton (NVIDIA) and Metal (Apple) kernels for MaxSim scoring in late-interaction models (ColBERT, ColPali). Numerically identical to PyTorch but far lower memory; supports fwd/bwd. Day-0 support for PyLate/colpali-engine. Strong for efficient multimodal RAG/retrieval. Link: https://x.com/i/status/2064701854815076566. Next step: Review the repo/code (search authors Tony Wu/Aurélien Lac), benchmark memory vs PyTorch on a small retrieval task.

- **Tailwind vs CSS Modules for AI coding efficiency**: Detailed controlled experiment measuring token usage, turns, and time when AI agents edit UIs. Tailwind cut tokens 39-55% and sped up sessions by keeping model in single file vs jumping files. Concrete, reproducible pattern for frontend + LLM workflows. Link: https://x.com/PixelJanitor/status/2064822864952676852. Next step: Read full results/setup, replicate the harness on a small React project with different styling.

- **9Router**: Open-source router for coding agents (Cursor, Claude Code etc.) across 40+ providers. Smart fallback, quota tracking, claimed 20-40% token savings via model routing. Practical AI engineering pattern. Link: https://x.com/VivekIntel/status/2064592322139173338. Next step: Find and clone the repo, test routing on mixed tasks.
