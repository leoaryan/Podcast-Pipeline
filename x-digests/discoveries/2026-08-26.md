## Investigate
- **MCP (standardized agent-tool protocol)**: Emerging protocol for AI agents to discover tools/resources (via `tools/list`), make standardized calls, and handle dynamic selection across models/providers. Configured via JSON for servers/credentials/capabilities. Includes enterprise governance (permissions, read-only), agent identities, micropayments, prompt injection protection. Multiple MCP servers (e.g., Box for controls, research/code/search tools). Turns apps/APIs into agent-usable endpoints with minimal per-client work. Why interesting: Foundational infrastructure layer shifting from custom integrations to standardized bridges; enables composable agent economies and self-evolving tool ecosystems. Next step: Search for MCP spec/docs or GitHub repos implementing MCP servers/clients; set up a simple server and test agent interaction.
  Links/examples from recent discussions: Gradio integration mentions, Box MCP, various tool suites.

- **cot-redteam-agent**: Local-first LLM red-teaming CLI + Python library (MIT, on PyPI) emphasizing visible chain-of-thought, proof-of-action (simulated tool effects and world-state changes), honest scoring (doesn't reward refusals as successes), OWASP LLM Top 10 tagging, interactive TUI, and CI gating (`scan` exits 0/1/3). Supports llama.cpp, vLLM, OpenRouter, OpenAI, Anthropic, mocks. Includes scenarios like Support Agent World. Repo: https://github.com/rudrasatani13/cot-redteam-agent. Why interesting: Real design philosophy for agent security testing—focus on observable reasoning and realistic evaluation rather than superficial benchmarks. Next step: Clone repo, install, run a scenario against a local model, inspect evaluation logic and TUI code.

- **5-agent specialized research desk pattern** (validated in arXiv paper): Instead of one monolithic LLM, decompose enterprise/analytics queries into five narrow agents—Query planner, SQL retriever, Statistical analyst, Charting/visualization, Report synthesizer—with coordinator synthesis. Achieves 95.3% functional accuracy and 93% hallucination-free on 300 real workloads. Why interesting: Empirical evidence that structural specialization + coordination beats general intelligence for grounded tasks; directly applicable to LangGraph/CrewAI setups. Paper: https://arxiv.org/pdf/2608.18740. Next step: Read the paper, prototype the agent roles in a framework, test on sample enterprise queries.

- **PromptCache + Model Affinity routing**: Open-source (MIT) semantic caching layer (PromptCache) with high/low similarity thresholds for exact vs. fuzzy hits, OpenAI-compatible endpoint, supports multiple providers, streaming on hits/misses. Complements native prefix caching. Paired with "model affinity" (session pinning via affinity_id header or task UUID) to route once per task and stick to one model for warm KV cache, avoiding cold prefill on drift. Addresses ~86% token burn from repeated agent context. Why interesting: Practical, implementable patterns for real cost/latency wins in production agent loops. Next step: Locate PromptCache repo (or implement minimal version), test semantic hits, experiment with affinity in a router like Plano.

- **Crilio**: CLI tool using an LLM "Judge" model for regression testing prompts/agents to catch hallucinations and block GitHub PRs before merge. Targets the "confident fabrication" problem in dev workflows. Repo: https://github.com/mukundzha/crilio. Why interesting: Automated, CI-integrated prompt evaluation with real guardrails. Next step: Clone and test on sample prompts/agents; compare to manual or other eval methods.
