# Discoveries — 2026-06-09

## Investigate
- **Abacus.AI Lite Agent Swarms**: Cost-optimized multi-agent system using frontier models (Opus 4.8 + GPT-5.5) for planning and cheap/fast models (DeepSeek Flash + Gemma) for execution. Claims ~10x cheaper, 2x faster with comparable results on parallel tasks like repo bug fixes and PR reviews. Includes video demo and implementation details. Why interesting: practical pattern for mixing models in agent swarms to optimize cost/performance. Link: https://x.com/abacusai/status/2064127425156702405. Next step: Review the shared implementation, test the planner/executor split pattern on a small task.
- **Local YouTube video generation pipeline**: Fully local setup with Hermes as orchestrator (on Mac for job mgmt, assets, upload), dedicated GPU machine running HyperFrames (Remotion-based rendering), Pinokio + Qwen3-TTS for voice, files transferred via SSH. Zero recurring cloud costs. Why interesting: clever unexpected integration of local AI tools, orchestration, and rendering to bypass paid services. Link: https://x.com/kaostyl/status/2063998683931095399. Next step: Examine the architecture details and see if components (Hermes + HyperFrames) can be replicated or extended.
- **HALO self-improvement loop**: Open-source loop for coding agents that enables self-improvement beyond basic prompting, works with any agent framework. GitHub: https://github.com/context-labs/halo. Why interesting: novel agentic workflow for iterative improvement. Next step: Clone repo, read the design, experiment with integrating into an existing agent setup.
- **Hindsight 0.8.0 agent memory with prompt caching**: Production agent memory system featuring default-on provider prompt caching for shared prefixes (retain/consolidate/reflect ops), full LLM tracing, de-duplication reducing duplicates from 30% to 1%, and resumable ops. Directly tackles token costs and latency. Link: https://x.com/Vectorizeio/status/2064004810441924686. Next step: Check the blog writeup and benchmark claims on caching impact.
