# Discoveries — 2026-07-01

## Investigate
- **Google ADK (Agent Development Kit) + Official Agent CLI**: Apache 2.0 open-source framework and CLI for building production-grade multi-agent systems. Supports orchestration, tools/APIs, memory, graph workflows, and integrations (GitHub, Jira, MCP, Google services). CLI handles scaffolding, evaluation with metrics, deployment to cloud, observability/tracing. Treats agents as real software systems rather than toys. Worth 2 hours to install, explore the CLI commands, and test a simple multi-agent workflow. https://x.com/DivyanshT91162/status/2071986130783023489
- **Squad (github.com/mco-org/squad)**: Multi-agent CLI coordination tool using a shared SQLite `messages.db` file (no daemons/sockets). Different AI coding agents (Claude Code, Codex, Gemini, OpenCode) collaborate; manager assigns, workers execute/report. Excellent for studying human-in-the-loop vs autonomous patterns. v0.7.6 recent. 2-hour test: clone, run a small task with multiple agents. 
- **agency-agents (github.com/msitarzewski/agency-agents)**: Repo with 232 specialized AI agent personas across 16 domains (engineering, design, etc.), each with personality, expertise, metrics. Philosophy of role-based specialization over generalists; examples run 8 agents in parallel with low coordination overhead. Integrates with Claude Code, Cursor, etc. 2 hours: explore personas, try running a multi-agent example. https://x.com/DataScienceDojo/status/2071594812290068627
- **LLM Checker**: Open-source CLI that scans hardware (VRAM/RAM/GPU/CPU), ranks best local LLMs from 33k+ models (HF, Ollama, etc.) by quality/speed/fit, with benchmarking and MCP server integration. Practical for multi-machine/local setups. 2-hour investigation: run on your hardware, evaluate top recommendations.
- **Prompt caching + model routing patterns**: Recurring practical LLM engineering signals—exact prefix caching for stable system prompts/tool schemas (49-80% cost wins), lightweight classifiers for routing to cheap/fast vs strong models (60-80% savings), structured output repair loops, observability first. Distinctions vs semantic caching. Worth 2 hours to implement a small routing + caching prototype in your stack.
