# Discoveries — 2026-07-16

## Investigate
- **AgentPrism Workflows** (https://github.com/VikashLoomba/agentprism-workflows): Apache-2.0 JS framework for writing code-defined multi-agent workflows with primitives like agent(), parallel(), pipeline(). Each agent independently selects harness (Claude Code, Codex, etc.) and model for cost-aware routing and fresh context. Includes MCP server. Strong emphasis on avoiding vendor lock-in and context pollution. Next step: Clone repo, run the examples, adapt a simple workflow to route between cheap and premium models.
- **TradingAgents** (TauricResearch/TradingAgents): Multi-agent LLM framework mimicking a hedge fund (fundamental analyst, sentiment, technical, trader, risk manager agents) in Python. Accompanied by arXiv paper. Practical for experimenting with agentic financial systems. Next step: Review the paper + repo, set up a minimal trading simulation with the agents.
- **Prompt caching & static-prefix architecture**: Recurring high-signal pattern for 50-90% input token savings by placing system prompts, tools, docs, and few-shots at the top (static prefix) with dynamic input at the end. Cache hits reset timers; combine with batching. One strong example beats multiples. Next step: Audit an existing prompt-heavy workflow, restructure for prefix caching, measure token/cost reduction on a provider that supports it (e.g., Anthropic).
- **Self-supervised tool learning (Toolformer-style)**: Model generates candidate API calls in special tokens, executes against real tools, keeps only those that reduce perplexity/loss, then fine-tunes. Enables smaller models (6.7B) to match larger ones on tool use without heavy labeling. Next step: Locate the original Toolformer paper + any recent implementations or replications mentioned; experiment with a small model + tool set.
- **Proto (Stanford/Arc Institute)**: Framework for composing 120+ incompatible biological AI models (proteins, DNA, RNA) via a shared language. AI agents can generate Proto programs. Foundational for computational biology. Next step: Find the project page or paper, understand the composition primitives, assess applicability to other domain-specific model orchestration.

## Interesting

- **dbvr (dbeaver/dbvr)**: Terminal-based database manager supporting the same wide range of SQL/NoSQL databases as DBeaver Community. Lightweight CLI alternative for multi-DB work.
- **Agensis Flow**: Single “Step” node workflow builder (prompts, code, tools, subflows, memory, agents) that can be packaged as deterministic code or OpenAPI-exposed virtual model. Extreme simplification for rapid agentic prototyping; MIT license, releasing soon.
- **Astronomer + Together AI on Astro/Airflow**: Agents that autonomously author, test, and PR Airflow DAGs + dbt models from tickets. 20x faster pipeline development, hundreds already in production.
- **Loose coupling via desktop AI agents (Claude Desktop, MCP, etc.)**: Instead of brittle tight API integrations for enterprise systems (Salesforce, ERP), add links/buttons that launch supervised desktop agents on specific records. 80-90% value with human oversight and minimal sandboxing.
- **Claude ecosystem as integrated stack**: Treating Chat (research/creative), Co-work (24/7 assistant with files/browser), and Code (app building) as specialized layers in one workflow for massive time/cost savings.
- **Advisor orchestration + split memory patterns**: Frontier model for planning/review only; delegate execution to cheaper models. Offload long-term memory to external stores (e.g., Redis) to keep prompt windows lean.
- **Myros**: Modular, extensible framework for real-time knowledge-aware AI agents with swappable retrieval, embeddings, memory, and interfaces.
