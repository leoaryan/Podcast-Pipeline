## Investigate
- **DeepSearcher (and deepdoc)**: Open-source Apache 2.0 framework for searching/reasoning over private/local data. Supports multiple LLMs (OpenAI, Claude, Gemini, Ollama, etc.), flexible document ingestion (PDF/TXT/MD + web crawling), vector DBs (Milvus, Qdrant, Zilliz), with CLI and FastAPI interfaces. Related deepdoc turns local docs (PDF, DOCX, images, TXT) into structured Markdown research reports.  
  Why interesting: Practical production-grade local/private RAG + agentic research setup that avoids cloud dependency.  
  Link: Search X for @DanKornas posts or GitHub (mentioned in recent threads).  
  Suggested next step: Find the repo, clone and run a test ingestion + query on sample local PDFs.

- **aibridge**: Lightweight bridge tool allowing one coding agent (e.g. Claude Code) to seamlessly call other CLI agents or tools. Originally for adding image generation to Claude, now used for cross-model code reviews and task delegation.  
  Why interesting: Solves unexpected integration / cross-agent calling without rigid pre-defined schemas; runtime extensibility angle.  
  Link: https://github.com/ycmjason/aibridge  
  Suggested next step: Clone, read README, set up a simple two-agent workflow (e.g. code review delegation).

- **Spine-Branch multi-agent framework** (Scale AI pattern): Pre-plans input/output dependencies for computer-use agents. One persistent "spine" carries live VM state; disposable "branches" handle parallel artifacts (no live machine merging). Reported +6–16.5% success rate, 34–70% cheaper, ~5× less overhead vs. traditional manager aggregation.  
  Why interesting: Concrete architectural pattern moving multi-agent systems from fragile to scalable/production. Directly addresses cost optimization and reliability.  
  Link: Recent X threads by @Yminglai or Scale AI discussions.  
  Suggested next step: Locate original description/post, sketch a minimal implementation or map to existing agent frameworks (LangGraph etc.).

  Why interesting: Core LLM engineering / cost optimization topic; practical for anyone running inference at scale.  
  Link: https://sankalp.bearblog.dev/how-prompt-caching-works/
