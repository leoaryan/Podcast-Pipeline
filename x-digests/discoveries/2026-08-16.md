## Investigate
- **DeepSeek Harness (dsh)**: Modular "agent operating system" with plugin architecture (inspired by spatiotemporal composability paper). Swap models, tools, UI at runtime without restart; includes web UI, file ops, code editing, shell, task delegation. MIT license, positioned as escape from proprietary harness lock-in. Repo saw explosive growth. Why interesting: Production-ready hierarchical agentic workflows + model routing + caching patterns in one clean design. Next step: Clone repo, explore plugin system and Excalidraw-mapped workflows.
  Link: https://x.com/hasantoxr/status/2088317043741491699 (and related threads)

- **OpenSandbox (Alibaba)**: Production-grade isolated sandbox for AI agents supporting code execution, web browsing, desktop control across tools like Claude Code/Cursor. SDKs in 5 languages, Docker/K8s/gVisor/Kata/Firecracker support, credential vault, MCP server ready. Apache 2.0, trending #1 on GitHub (12.5k+ stars). Why interesting: Real infrastructure for safe agent tooling rather than toys; multi-runtime isolation is a core constraint worth studying. Next step: Review GitHub repo and SDK examples for isolation mechanisms.

- **FactoryAI Model Routing in Harness**: Detailed production data on routing logic living in the agent harness (not just inference gateway): 58% aggregate cost reduction, 76% median session savings, latency drops, while preserving quality. Accounts for cache state, session trajectory, sub-task roles (planner/worker/reviewer). Why interesting: Concrete metrics + cache-miss penalties in long agent sessions; directly actionable AI engineering pattern. Next step: Read the full thread and compare to Hermes prompt caching behavior.

- **apkget CLI**: New Go-based open source CLI for searching/downloading Android packages (APK/XAPK/etc.) with reverse engineering via Apktool + JADX, multi-provider fallback. Why interesting: Focused, practical CLI tool with clear design philosophy around reliability and RE workflow. Next step: Install and test on sample APKs to evaluate UX and integration points.
