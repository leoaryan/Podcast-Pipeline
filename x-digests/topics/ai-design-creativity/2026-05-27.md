# AI in Design & Creativity
**Date:** 2026-05-27

## Key Examples
- Non-technical designers running full workflows from the terminal using Claude Code + Figma MCP, achieving 5x output while keeping taste fully human.
- Agentic pipelines where a single prompt handles Linear ticket → Figma asset scraping → implementation → verification via CLI screenshots → PR creation.

## Insights
- The biggest shift is from tool mastery to orchestration and taste. Designers getting the most leverage treat AI as a high-speed junior that needs strong direction.
- MCP-style integrations are becoming the real differentiator by removing massive context-switching friction.

## Notable Opinions
- “Taste is becoming the only moat.” Prompting skill is now table stakes.
