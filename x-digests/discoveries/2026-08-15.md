# Discoveries — 2026-08-15

## Investigate
- **Konkord (LLM Evaluation Tool)**: Local-first tool for pairwise model comparisons that measures human vs. judge agreement, Cohen’s kappa, position bias (by swapping order), and Bradley-Terry rankings with confidence intervals. Addresses instability in LLM-as-judge leaderboards (e.g., 43% flip rates). MIT licensed, outputs JSON, supports custom tasks/rubrics. Worth 2h to test on real eval tasks and see bias stats. Post: https://x.com/i/status/2088521070210871779 (repo/docs linked there).
- **DeepSeek Harness (DSH)**: MIT-licensed modular agentic framework built on “everything is a plugin” with spatiotemporal composability and swappable components/multiple runtimes. Strong design philosophy for flexible AI agents. Investigate by cloning and experimenting with plugin system. Post: https://x.com/i/status/2088487621446287692.
- **Plan-then-Apply / Dry-Run + Commit Pattern**: Agents must first output a detailed plan/diff (blast radius, rollback, preconditions) before any side-effect actions; reviewed (human/policy/auto) then committed/executed. Software-engineering guardrail treating LLM actions like Terraform apply. Highly practical for safe agentic systems. Next step: Prototype in a simple agent loop. Discussed in multiple threads on agent safety.
- **Prompt Caching Prefix Strategy & Context Engineering**: Place all static content (system prompts, examples, tools, schemas) first; dynamic/variable input last. Cache reads ~10% cost. Changing early tokens invalidates cache. Evolved prompt engineering into full context design for high ROI. Test by restructuring prompts and measuring hit rates/costs. Multiple engineering threads.
- **Hermes Plugin Event Bus + Live Token Stream Hooking**: Plugins can react in real-time to live LLM token streams and each other via full event bus, with capability declarations, consent, and additive design. Turns runtime into reactive platform with emergent behaviors. Directly relevant; worth exploring plugin development/docs.
