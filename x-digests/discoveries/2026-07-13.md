# Discoveries — 2026-07-13

## Investigate
- **fabric CLI**: Terminal tool that pipes text/tasks through 255 pre-built, task-specific AI prompt patterns compatible with any LLM. Open-sourced collection from Daniel Miessler (cybersecurity researcher). ~43k GitHub stars, MIT license. Turns terminal into an AI power tool with real design philosophy around reusable patterns. Worth cloning and testing patterns on real workflows.  
  Link: https://x.com/Granite0x/status/2076376825278988670 (search for fabric Miessler GitHub for repo)

- **BMAD-METHOD (12-agent AI framework)**: Open-sourced 12-agent methodology + 34+ workflows designed as drop-in for Claude Code. Guides full project lifecycle: brainstorm → PRD → architecture → shipped code. Created by ex-NASA/Northrop engineer. ~50k stars, MIT. Practical production-grade agentic dev system.  
  Link: https://x.com/ArchiveExplorer/status/2076271402047373519

- **Multica (AI engineering squad)**: Open-source tool that assigns GitHub-style issues to autonomous AI agents. Agents handle tasks end-to-end: pick up work, code, report blockers, update status. Integrates with Claude Code, Copilot, etc. Realizes "AI team" pattern for issue resolution. Free, immediately usable.  
  Link: https://x.com/QCXINT_/status/2076249517931077894

- **Dynamic DAG multi-agent architecture**: Novel pattern from recent work where a Manager Agent converts tasks into editable directed acyclic graphs. Subtasks run in parallel with dependency respect; manager dynamically replans on failures/changes. Reported 3–25% gains and 1.5× speed on long-horizon tasks. Explicit dependency structure + editability is the key insight over naive parallelism. Worth reading the referenced paper/thread for implementation ideas.  
  Link: https://x.com/SMishra61/status/2076227563643716060

- **Model routing + RouterLLM patterns**: Practical cost/quality optimization via dynamic routing (complex tasks → frontier models; simple → lighter/open-source). Tools like Abacus.ai ChatLLM/RouteLLM highlighted for building routers mixing models without code. Avoids overpaying on every prompt. Strong signal for real engineering practice.  
  Links: https://x.com/i/status/2076344539938451908 and related routing threads
