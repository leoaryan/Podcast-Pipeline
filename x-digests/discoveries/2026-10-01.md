Features in-app plugin manager, PDF/spreadsheet analysis, chart/slide generation, scheduled automation tasks, and experimental “creator mode” for describing and auto-building plugins. Strong focus on dev workflows and sandboxing. Worth 2 hours to explore the plugin architecture and agent extensibility patterns. Link: https://x.com/DeepSeekHarness/status/2105330281389662575 Suggested next: Review any linked docs/GitHub, test plugin installation and creator mode.

Enables agents (Claude Code, ChatGPT, Hermes, custom) to connect directly to models from existing workflows without heavy switching. Early demos include photo diaries to animated shorts with voice cloning. Interesting for unconventional vision/AI agent integrations. Docs: hedra.com/mcp Link: https://x.com/i/status/2105342577725546681 Next: Read docs, experiment with agent-to-model connections.

Niche but clean design for document workflows. GitHub: https://github.com/bennof/edotex Worth checking the architecture and server capabilities. Next: Clone and test the binary/server locally.
