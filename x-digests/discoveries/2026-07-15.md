- **DeepTeam** (LLM red-teaming/security framework with CLI): Open-source tool with 50+ vulnerability checks, 20+ attack techniques (prompt injection, jailbreaks, multi-turn, multilingual), supports OWASP/NIST/Mitre, runs locally with any provider, YAML config + Python API + CLI. Why interesting: Concrete, production-ready patterns for hardening agents/RAG/chatbots rather than abstract advice. Next step: Clone repo, run CLI against a sample agent or RAG setup to explore the checks.
- **Proto** (Biology/AI model composition framework): Stanford/Arc Institute open-source framework composing 120+ incompatible AI biology models (proteins/DNA/RNA design) via shared language; supports natural language descriptions and even agent-generated programs. Why interesting: Novel mechanism for bridging incompatible specialized models in a scientific domain with real agentic capabilities. Next step: Review GitHub/docs for the shared language primitives and composition examples.
- **h5i** (Hardened isolation workflow for coding agents): Uses isolated worktrees/environments (`h5i init`, `env create/diff/propose/apply`) to sandbox agent changes (e.g., Claude Code) beyond prompt rules. Why interesting: Practical distributed-systems-style safety layer for autonomous coding agents that actually execute in terminals/filesystems. Next step: Install and test the workflow in a controlled repo to see review/merge flow.
- **State machines for voice AI pipelines**: Insight that fragmented state across STT/LLM/TTS causes subtle failures (old tasks, noise misfires); fix via single runtime owning full conversation lifecycle with audio-as-events. Why interesting: Classic engineering pattern (state machines) outperforming model upgrades in real voice systems. Next step: Search for open implementations or adapt the pattern to a simple voice agent prototype.
