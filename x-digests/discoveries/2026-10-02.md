# Discoveries — 2026-10-02

## Investigate
- **Forge (Cloudflare)**: Open-source pipeline for generating SDKs, CLIs, docs, and artifacts from OpenAPI 3.x specs. Runs in CI on PRs, pluggable chainable transformers (e.g., TS SDK → CLI), local/CI-native (no SaaS), Apache-2.0. Philosophy: treat API artifact generation as first-class composable CI process to eliminate sync maintenance at scale (3500+ ops). Worth 2h to explore repo, try on a small OpenAPI spec, understand transformer architecture. Links: https://x.com/sayandedotcom/status/2105782755678384154 (and related cf CLI post).
- **cf CLI (Cloudflare)**: New open-source agentic CLI for full Cloudflare API. JSON-first output, TS config, built-in search, Vite dev experience, explicitly "agent-ready". Design for both humans and autonomous agents consuming APIs frictionlessly. Investigate architecture and how it enables agent workflows. Link: https://x.com/aidevnewss/status/2105407934918496581
- **OpenCastle**: MIT open-source CLI for centralized AI assistant config management across tools (Claude, Copilot, Cursor, etc.). Single source of truth compiles to native formats, repo init, CI drift detection (--check). Treats AI config/rules as code with version control and quality gates. Strong philosophy for multi-tool AI engineering teams. Link: https://x.com/DanKornas/status/2105398311175716927
- **MCP "code mode" + script bridges**: Pattern where agents write small JS scripts (QuickJS sandbox) to handle nested/complex tool calls (e.g., >300 calls with one summary returned). Progressive discovery, dynamic schema exposure over static codegen. Enables scalable, inspectable tool use without context bloat. Investigate implementations (e.g., in Pi or similar tools) and extensions for visualization. Links: https://x.com/AmrTawfik160/status/2105457673533546705, https://x.com/Howaboua/status/2105342323735318840
- **Agetor Pipelines & Multi-Agent Graphs**: Reusable pipeline graphs chaining specialized agents (different models/instructions/skills per step), with context handoff, safety (step caps, retries), shared worktrees, CLI export. Shifts to repeatable multi-model workflows. Worth exploring for agent orchestration patterns. Link: https://x.com/alamosaravali/status/2105455154044731612
