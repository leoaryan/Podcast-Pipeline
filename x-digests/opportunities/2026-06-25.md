## 🔬 Methodology Deep Dives

### 1. Axel_bitblaze69 — Battle-Tested Claude Code Agent Architecture (March 2026)
**Source**: https://x.com/i/status/2037978621684621428 (thread on persistent multi-agent systems with Claude Code).

**Methodology extracted**:
- Treat Claude Code as autonomous runtime, not autocomplete.
- Core control: `.claude/` folder committed to git.
  - `CLAUDE.md` (<200 lines): loads into every system prompt — build/test commands, architecture rules, naming, gotchas. Keep short to maintain adherence.
  - `rules/` folder with YAML frontmatter for scoped rules.
  - `Skills/` as self-contained `SKILL.md` workflows that auto-trigger on context or `/command`.
  - `Hooks/`: deterministic shell scripts on PreToolUse/PostToolUse/Stop events (auto-lint, security gates, "tests must pass or you're not done").
- Sub-agents: Main agent spawns specialized (Explore/Haiku for cheap research, Plan for architecture, security-reviewer with restricted tools). Prevents context pollution.
- MCP (Model Context Protocol): Universal connector to GitHub, DBs, Slack, Figma, browser — turns agent into orchestration layer.
- Workflow patterns: "Interview me" for clarifying questions; Research → Plan → Implement split; parallel worktrees; aggressive context management (`/clear`, `/compact`); Memory + Plan Mode for compounding knowledge.
- Always plan big changes first.

**Tool stack & why**: Claude Code primary; compares favorably to Cursor for full workflows. Ecosystem: `superpowers` skill for 7-phase TDD + subagents.
**Architecture diagram (text)**: Persistent .claude/ control plane → MCP tool layer → Sub-agents (isolated) → Hooks for verification → Git worktrees for isolation.
**Non-obvious insight**: Declarative memory files + event-driven hooks + sub-agent isolation create compounding, self-correcting systems that outperform repeated prompting or single long-context chats. The "less is more" curation (short CLAUDE.md, limited skills) is what makes it reliable at scale.
**What we can apply directly**: Adopt .claude/ + CLAUDE.md + Skills/Hooks pattern in Hermes/VPS setups for persistent agent memory and deterministic automation. Score: Novelty 4, Actionability 5, Depth 5, Relevance 5 (Total 19/20).

### 2. Mnimiy — Ruthless Skill Curation for Claude Code (May 2026)
**Source**: https://x.com/i/status/2051701429987897712 (tested 247 skills, kept 23).

**Methodology**:
- Marketplace exploded to 900k+ contributions; most are noise/context tax.
- Distinguish **discipline skills** (enforce process/aesthetics/style — drive quality) vs **capability skills** (new abilities like scraping).
- Tier S (install on every machine): `frontend-design`/`impeccable` (kill AI-slop UI), `superpowers` (brainstorm→spec→plan→TDD→subagents→review), `simplify` (clean code), `skill-creator` (meta), `web-design-guidelines` (audits).
- Install order: Start with 4 foundations, add slowly. Audit ritual: Disable anything not firing in 30 days.
- Rule: 5–7 active skills max.

**Non-obvious insight**: Most skills fail due to outdated hooks, conflicts, no measurable lift, or context bloat. The highest leverage comes from process-enforcement skills rather than raw new capabilities.
**What we can apply directly**: Curate a minimal Hermes skill set focused on discipline (TDD, simplification, design review) before adding capability tools. Score: Novelty 3, Actionability 5, Depth 4, Relevance 5 (Total 17/20).

### 3. Multiple Solo Builders — Agent-as-Teammate + Conductor Model (2026 threads)
**Sources**: Aggregated from https://x.com/i/status/2046333601302925536, https://x.com/i/status/2064829133595845100, https://x.com/i/status/2063081765544317107.

**Methodology**:
- Build virtual org chart: Each agent gets job-description prompt (what they do, explicit red lines, personality, output format).
- Chain: Triager → Coder → Reviewer (picky, no merge) → Reporter.
- Human role: Architect/conductor (direction, design, review gates, business calls). Agents handle execution.
- Loops: Triggers + SKILL.md/SOP + STATE.md + git worktrees + maker/checker sub-agents + objective verifiers (tests/CI).
- 10-step framework: Only loop repetitive/verifiable/economically viable tasks; estimate token costs; rich context; hard stops/human gates on irreversible actions.
- Solo example: One dev shipped 21 OSS projects in a month using strict session discipline (read THEME.md + prior code first).

**Non-obvious insight**: Distribution/validation beats complex tech; start with one agent proving end-to-end flow; human stays in loop for merges/money/judgment while agents run the repetitive. "Become the conductor" compounds faster than being the executor.
**What we can apply directly**: Structure Hermes agents with explicit roles/red lines + conductor oversight for our pipeline. Score: Novelty 4, Actionability 5, Depth 4, Relevance 5 (Total 18/20).

### 1. MCP Servers (Model Context Protocol)
**What it does**: Scoped tool servers giving agents persistent, permissioned access to filesystem, GitHub, Postgres, Brave Search, Fetch, etc. (never direct DB access in some impls).
**Why it matters**: Shifts from prompting to real orchestration/integration layer. Multiple solo devs report $5k+/mo from this pattern.
**Composes with**: Claude Code skills, sub-agents, any agent framework (LangGraph, CrewAI).
**Adoption signals**: One dev maintains 37 open-source MCP servers (35k+ monthly installs); AGENTS.md included for agent consumption. https://x.com/Nekt_0/status/2064394968764973566, https://x.com/delx369/status/2064392224289288690.
**GitHub examples**: Various self-hosted MCP servers (MIT). Score: Novelty 4, Actionability 5, Depth 4, Relevance 5 (Total 18/20).
