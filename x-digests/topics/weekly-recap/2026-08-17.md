## Items worth Aryan's time

**Source:** @KhuyenTran16 — https://x.com/KhuyenTran16/status/2087177878555226250
**What happened:** Detailed explanation of Hermes' two automatic skill-management workflows: *Crystallization* (creates a reusable skill after a complex task completes) and *Curator* (tracks usage, archives stale skills, suggests consolidations). Real-world testing on debugging tasks showed measurable reduction in manual overhead as skill libraries grow.
**Why it matters:** Directly solves the "skills library maintenance problem" that emerges once you have more than a handful of reusable procedures. Concrete automation loop, not abstract advice.
**Route:** Build
**Next smallest action:** Review the Crystallization + Curator prompts in your current Hermes setup and test one on a recent debugging session.

**Source:** @HermesWatcher — https://x.com/HermesWatcher/status/2087569964484247804
**What happened:** Practical Hermes cron optimizations: use `no_agent=True` for pure-script tasks, add pre-run scripts that only wake the full LLM if context has meaningfully changed (e.g., new data detected), and reserve full agent runs for judgment-heavy work like summarization or comparison.
**Why it matters:** Prevents unnecessary LLM wake-ups on every cron tick while keeping quality where it counts. Directly applicable to your existing digest and discovery crons.
**Route:** Build
**Next smallest action:** Audit one of your active Hermes cron jobs (e.g., the weekly recap or Hermes Discovery) and add a context-change gate.

**Source:** @zivuch — https://x.com/zivuch/status/2089246185718431786
**What happened:** Launched MnemoDB, an open-source structured memory system for AI coding agents. Stores each memory as a human-readable `.mem.md` file with provenance tracking, git-diff support, fast keyword search, and portability across tools (Claude Code, Cursor, etc.).
**Why it matters:** Concrete solution to the "forgets everything between sessions" problem. File-based format makes inspection, versioning, and cross-tool use trivial.
**Route:** Scout / Build
**Next smallest action:** Clone MnemoDB and test importing one of your existing agent memory contexts into the `.mem.md` format.

**Source:** Multiple threads on Agent OS patterns (notably @JulianGoldieSEO and related) — example thread https://x.com/JulianGoldieSEO/status/2089109957253685691
**What happened:** Emerging discussion of unified "Agent OS" architectures (Hermes Agent OS / Claude Agent OS) that combine specialized agents (Hermes Oracle for scanning, Jarvis for computer control, Memory Galaxy for Obsidian sync) with autonomous Builder + Judge loops that iterate until quality thresholds are met.
**Why it matters:** Moves beyond single agents or disconnected tools toward persistent, collaborative, self-critiquing systems with shared memory — exactly the direction of your daily-digest and portfolio OS work.
**Route:** Learn
**Next smallest action:** Watch one of the linked long-form videos or the free 3-hour course on building such systems and map the top 2 components against your current cron + skills setup.
