### Hermes cron suggestions and persistent automation patterns
- **Source:** @IBuzovskyi — https://x.com/IBuzovskyi/status/2098124038954451435 (and related @NousResearch threads)
- **What happened:** Hermes now surfaces cron job suggestions based on observed manual patterns (e.g., “you check inbox every morning → propose 7am cron”). Accepted suggestions become versioned, persistent automations with skills attached, context chaining, and silent modes via no_agent=True.
- **Why it matters:** Turns ad-hoc work into compounding OS loops without manual crontab or shell scripting. The /suggestions command observes real usage and proposes guardrails like “Disciplined Vibe Coding.”
- **Route:** Build
- **Next smallest action:** Run `/suggestions` in your Hermes session and accept one cron for a recurring research or digest task.

### Hierarchical multi-agent Morning Jarvis with specialized Discovery Feed
- **Source:** Detailed workflow thread (synthesized from recent agent design posts, e.g., https://x.com/i/status/2098211844720669077 and related)
- **What happened:** A first-principles breakdown of a morning briefing system using Jarvis Prime (orchestrator + user model), parallel Context Collectors (personal state, world pulse, Discovery Feed Agent), First Principles Synthesis Agent, and Delivery/Feedback loop. Discovery Feed ranks by insight density, cross-domain leverage, and novelty vs user history.
- **Why it matters:** Moves beyond headline aggregation to autonomous overnight synthesis that surfaces unknown unknowns and maintains memory/feedback for iterative improvement. Explicitly decomposes topics to atomic truths before rebuilding for the user.
- **Route:** Learn / Build
- **Next smallest action:** Prototype the Discovery Feed Agent ranking criteria in a small Hermes skill and test one overnight run.

### Fable as executive layer with subagent delegation for agent systems
- **Source:** @Pakgowithai, @AnAIRenaissance, @Sami_Sytela and related — https://x.com/Pakgowithai/status/2099277239409844361, https://x.com/AnAIRenaissance/status/2097022307915165733
- **What happened:** Practitioners route Fable (Claude Fable 5/5.1) as the main orchestrator for complex agent workflows (planning, review, multi-agent assembly) while delegating mechanical tasks to cheaper/faster models via env vars like CLAUDE_CODE_SUBAGENT_MODEL=opus. Shows strong results on GDPval and Real-SWE benchmarks with fewer turns; benefits from cache pricing and 1M context.
- **Why it matters:** Efficiency comes from model routing, not raw intelligence per token. Makes long-horizon, stateful agent loops production-viable without exploding costs. Common pattern now in agentic coding/research factories.
- **Route:** Scout / Build
- **Next smallest action:** In your next multi-agent prototype, explicitly set a lead model (Fable or equivalent) and test subagent delegation on one workflow.
