  Link: https://x.com/mikenevermiss/status/2063185338156163396  
  Next step: Find the GitHub repo, test minimal 2-3 Mac setup for local inference.

Devil’s Advocate), integrity agent for citations/stats, LaTeX-to-PDF. Open-source `.claude/skills/` drop-in. Scores your contribution post-run.  
  Link: https://x.com/HowToAI_/status/2063142935798145429

- **NotebookLM + Gemini Gems + Google Apps Script bridge**: No-code system where NotebookLM acts as GAS expert knowledge base, custom Gemini Gems translate Japanese natural language to code, executed in GAS. Reproducible templates for Gmail, Sheets, Forms, Slack, PDF reports. Eliminated 100+ hours/month overtime.  
  Link: https://x.com/ai_jitan/status/2063365478156742768
