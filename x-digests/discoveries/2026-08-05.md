## Investigate
- **Not Diamond Code** (intelligent model router for long-horizon coding agents): Cache-aware and session-aware routing that predicts future rewards/costs across agent trajectories, mixes models (including open-source), claims 20-65% cost reduction with no quality loss or better. Integrates with Claude Code and other harnesses via local proxy. Strong benchmarks on SWE-PolyBench and LongCodeQA. Why interesting: Moves beyond simple complexity classifiers to true orchestration primitives that respect KV cache and long sessions—core for expensive agent workloads. Links: X discussions around launch (e.g., @artic_ai reactions). Next step: Find official site/repo, test integration with existing agent setup, review benchmarks and cache logic.
- **Vercel Agent Browser** (Rust-based local CLI/browser control for AI coding agents): Enables agents (Cline, Cursor, Codex, etc.) to perform real browser actions (click, scroll, fill forms, read content) without custom Selenium scripts. Runs as fast native binary locally. Why interesting: Bridges the gap between LLM agents and real web interaction in a clean, script-free way—practical for agentic web tasks. GitHub: https://github.com/vercel-labs/agent-browser. Next step: Clone, build/run locally, test with a simple agent workflow.
- **Plano** (open-source LLM router): Minimal-change routing (2-line config pointing base_url to local endpoint) based on prompt intent; includes observability for decisions, costs, and model choice. Self-hostable via Docker; reported ~2x bill reduction. Why interesting: "Set and forget" cost optimization and model mixing without rewriting agent logic—unexpectedly simple bridge between tools. Next step: Check GitHub (search PlanoAI or related), deploy locally, benchmark against hardcoded models.
- **aci.dev** (open-source tool-calling platform): Unified access to 600+ SaaS tools for agents with OAuth, secrets, permissions, dynamic discovery, logging, and MCP server support. Apache 2.0. Why interesting: Solid infrastructure layer for production agent-tool interactions beyond basic function calling. Next step: Review docs/repo (aci.dev), compare to existing tool-use patterns like LangChain or custom MCP.
- **Shellular** (multi-agent coding environment): Quick-setup (<3 min) setup combining multiple models (Claude, Codex, etc.) with persistent terminals, localhost visibility, JS console. Why interesting: Practical multi-agent dev workflow that reuses existing subscriptions and feels native. Demo: YouTube video linked in posts. Next step: Watch demo, replicate setup, evaluate for daily coding.
