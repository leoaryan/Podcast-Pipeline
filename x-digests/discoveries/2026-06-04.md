# Discoveries — 2026-06-04

## Investigate
- **MACU (Multi-Agent Computer Use)**: Framework using a manager LLM to decompose tasks into a DAG of subtasks dispatched to multiple parallel worker agents, with dynamic re-planning. Reports 3–26% higher success rates and reduced completion times on long-horizon tasks (e.g. Odysseys suite). No custom training needed. Strong candidate for deeper look into orchestration patterns.  
  Link: https://x.com/yesnoerror/status/2062278674112548891  
  Next step: Find the open-source repo/code and paper; run a simple example if available.

- **Prompt prefix / system-prompt caching patterns**: Multiple engineers reporting 60-80% cost reductions (one case 98% hit rate saving >12.5M tokens) by caching repeated prefixes. Treat as architecture decision rather than afterthought. Highest-leverage LLM engineering lever currently underused.  
  Links: https://x.com/dvsobo/status/2061936193932247415, https://x.com/adityacholkar/status/2062202293429457133  
  Next step: Review specific implementation details and caching TTL/config examples across providers.

- **New Rust + Ratatui TUIs replacing web UIs**: Cluster of polished single-binary tools including quokka (iOS/Android device explorer over USB), dehub (unified GitHub PR/Issues/Actions TUI), rainfrog (vim-style Postgres TUI with autocomplete). Signals a broader trend toward fast terminal alternatives for dev workflows.  
  Links: https://github.com/dutradotdev/quokka, https://github.com/DamianB-BitFlipper/dehub, https://github.com/achristmascarl/rainfrog  
  Next step: Clone and test 1-2; evaluate Ratatui patterns for building similar tools.

- **llxprt-code**: Open-source multi-provider AI-assisted CLI coding tool supporting any LLM directly in terminal. Fits the AI-native terminal tooling wave.  
  Link: https://github.com/vybestack/llxprt-code  
  Next step: Install and compare workflow against existing tools like Claude Code or Cursor CLI.
