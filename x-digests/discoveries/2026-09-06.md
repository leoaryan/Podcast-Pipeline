3. **Structured Output + CoT Schema Trick** — Enforce explicit Chain-of-Thought in structured JSON outputs by placing a mandatory `reasoning_steps` (or thinking/explanation) field *first* in the schema, before result fields. Prevents models from jumping to answers and improves quality/reliability. Simple, high-leverage pattern for LLM engineering.

   Suggested next step: Implement in a test script with a model supporting structured outputs (e.g., via OpenAI/Anthropic SDK); compare outputs with/without the field on a reasoning-heavy task.

4. **Pre-computation Snapshot Pattern for Agents** — Run deterministic scripts upfront to build clean data snapshots instead of relying on live tool calls during agent execution. Example (accounting agent): reduced query time from 583s to 92s, tool calls from 33 to 1, cost from $1.13 to $0.13, accuracy from 2/13 to 11/13 issues caught. Key insight for cost/performance in production agents.

   Suggested next step: Pick one agent workflow involving data/tools, implement a pre-snapshot script, measure before/after metrics.

5. **Prompt Caching Design + LiteLLM/Portkey Routing** — Structure prompts with static content (system prompts, tools, RAG context) at the very beginning for maximum cache hits (often 50-90% token/latency savings). Use lightweight proxies like LiteLLM or Portkey for unified routing, failover, tracking, and cheap-first model selection across providers.

   Suggested next step: Set up LiteLLM as a local proxy, refactor one existing prompt for caching, run cost/latency benchmarks before and after.
