# Hermes Agent Applications
**Date:** 2026-06-03

## Key Examples
- **Hermes Desktop launched by @NousResearch** — Native desktop app for macOS, Windows, and Linux with one-click install, full file/app access, real-time tool output, voice, and remote gateway mode (point it at a Hermes backend on a VPS with a session token). This is a major leap: it moves Hermes from terminal-only to a full desktop OS, bringing persistent agent capabilities directly to non-technical users. The app is MIT-licensed and open source. Source: x.com/i/status/2061843507417944552
- **Nous Portal replaces API key sprawl** — A single subscription backend for powering Hermes Agent with access to a wide range of models plus hosted premium tools. Run `hermes portal` in terminal to switch. Users describe it as "insanely good value" even for non-Hermes agents because it eliminates the overhead of managing multiple API keys and model endpoints across providers. Free tier available. Source: x.com/i/status/2061973480527036681
- **Hermes Skills Hub is now a marketplace with hundreds of ready-to-use skills** — Covering AI agents & coding, research & content creation, web scraping (stealth browser with Cloudflare/captcha bypass), lead generation with natural language ICP, funnel analysis (connects to GA/Stripe/Notion), and NVIDIA-specific workflows (CUDA-X, Omniverse, Physical AI, NeMo). The key insight: instead of building from scratch, you browse and install proven skills in minutes. The agent remembers workflows, corrects them in chat, and converts them into persistent skills that survive rebuilds. Source: x.com/FM_yassin/status/2061886912261214609
- **Progressive 4-level multi-agent setup from @shannholmberg** — Level 1: single main agent prototyping. Level 2: cloned specialized agents (SEO, CMO, Ops, Researcher, Writer, Builder, Reviewer) each with their own SOUL.md. Level 3: dedicated Orchestrator routes tasks to specialists via Kanban/goals. Level 4: fully automated via cron + Hermes Dreaming (v0.3+) where supervisor agents monitor logs, detect bugs, propose fixes, verify with peer supervisors, and auto-apply low-risk changes. "Quality > Quantity of agents. Invest time crafting excellent saved skills — this is where leverage comes from." Source: x.com/shannholmberg/status/2056410242330874349

## Insights
- Hermes is evolving from a terminal coding agent into a full **Agent OS** — desktop app, portal subscription, skills marketplace, multi-agent orchestration, and self-healing via Dreaming. The 2026 trajectory mirrors what happened with operating systems: it's becoming a platform others build on, not just a tool you use.
- **Skills are the atomic unit of value.** The community isn't focused on better prompts — it's focused on packaging proven workflows as reusable, installable skills. This shifts the competitive moat from model access (commoditizing) to workflow knowledge (compounding). The Skills Hub + NVIDIA partnership suggests domain-specific skills (robotics, Physical AI) are the next frontier.
- The "do not automate slop" principle is gaining traction: refine output with a single agent first before spawning 10-20 agents. Scaling bad work creates faster garbage. This is a counter-narrative to the "throw more agents at it" hype.
