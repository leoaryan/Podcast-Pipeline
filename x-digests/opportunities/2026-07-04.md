## 🔬 Methodology Deep Dives

**1. ReAct + 5-Block Reliable Agent Architecture (Synthesized from multiple 2026 practitioner threads, e.g. @tyrtyre201, @i/status threads)**
- **Who**: Active builders sharing on X in mid-2026 (e.g. tyrtyre201 thread on scope and architecture).
- **What they built**: Robust agent systems moving beyond one-shot prompts to self-correcting workflows.
- **Step-by-step methodology**:
  1. Decide scope ruthlessly: One sentence goal, exact success/failure moment. Cut anything not core.
  2. Implement core ReAct loop: Goal → Think → Act (tools) → Observe → Reflect → Retry → Done.
  3. Build the 5 blocks: Brain (LLM like Claude/M3), Tools (search, file, MCP), Memory (short-term trace + long-term notes with STEP COMPLETED format), Loops (Critic for reflection), Verification (explicit checks on correctness/goal).
  4. Start minimal (~50-line Python while loop), add tools (Tavily/Brave, file ops), memory + reflection prompts, then Critic, then multi-agent orchestration.
  5. Use frameworks for production: LangGraph for checkpoints/retries, CrewAI for patterns, Claude Projects/MCP for tools, Hermes for persistent self-improving agents.
- **Tool stack + why**: Claude ecosystem (Projects, Code, MCP for Gmail/Slack etc.) for non-technical speed; Hermes (Nous Research) for memory/learning loops on local vaults; Obsidian for ground-truth Markdown graph; MiniMax M3 or long-context models for vault-scale reasoning. Local-first with Ollama for dev.
- **Architecture decisions**: Narrow specialists over human-org-chart roles; persistent memory to prevent loops/repeats; human-in-loop for high-stakes; verification before any action.
- **Mistakes fixed**: Over-scoping (generic agents abandoned); no memory (repeats errors); no verification (silent failures); too much autonomy early.
- **Non-obvious insight**: The hardest part is "what NOT to build" — focused narrow agents at 95% reliability get daily use; broad ones at 40% get abandoned. Compounding comes from reliable scheduled self-improving loops, not model size. Start with one hated manual task this week, iterate 5-10x.
- **What WE can apply directly**: Integrate ReAct + verification into existing Hermes skills; add reflection/critic prompts to agent pipelines; point Hermes at Obsidian vaults for knowledge automation. Score: Novelty 3, Actionability 5, Depth 4, Relevance 5 (Hermes/Obsidian alignment). Total 17/20.
- **Source**: https://x.com/tyrtyre201/status/2066826145119588796 and related threads.
