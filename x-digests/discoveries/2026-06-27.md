- **Loop Engineering & self-running agent systems**: Emerging pattern (discussed by LangChain's Harrison Chase and others) shifting from manual prompt engineering to designing autonomous loops: agents that grade their own outputs, trigger on events, maintain persistent state (issues/logs), use critic patterns (never self-grade), and iterate via tools/tests. Real examples like Stripe's "Minions" (1,300+ machine PRs/week). Related tools like GenLayer’s “Unhardcoded” for declarative model policies/routing.  
  Why interesting: Core evolution in AI engineering for production-grade agent reliability and cost control; includes model routing (planning on strong models, execution on cheap) and KV-cache/prompt caching metrics.  
  Links: https://x.com/VoltexGar/status/2070595903136616536, https://x.com/heyrimsha/status/2070128370747416884, https://x.com/BadiuTweet/status/2070427074997686669
