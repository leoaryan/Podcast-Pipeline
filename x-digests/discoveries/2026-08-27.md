## Investigate
- **Graphify**: Fully open-source tool that parses any codebase/folder into a navigable knowledge graph (no vector DBs or config). Outputs Obsidian vault with backlinks, wiki-style index, and plain-English Q&A. Uses two-pass system (local parsing + subagents for concepts from docs/images). Claims 71.5x token reduction for AI agents by querying the compact graph instead of raw files. Supports 13 languages, PDFs, Markdown, images; integrates with Claude Code/Cursor. Repo: https://github.com/Graphify-Labs/graphify. Next step: Clone repo, run on a sample codebase, measure token savings and graph quality vs naive RAG.
- **Unlimited OCR (Baidu 3B model)**: Compact open-source (MIT) 3B-parameter model that processes entire 100-page PDFs in one pass (32K context), preserving tables, formulas, reading order. Runs locally/offline on standard inference backends with strong benchmarks. Strong fit for document intelligence pipelines, research, contracts. Next step: Locate the model weights/repo (search Baidu or Hugging Face), test on a multi-page PDF sample, compare accuracy/context retention to alternatives like standard OCR + LLM.

Enables true stateful agentic pipelines without losing context between sessions. Next step: Review the integration announcement/details, set up a minimal Dify + EverMind test workflow, evaluate memory persistence on multi-turn tasks.
