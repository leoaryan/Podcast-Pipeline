# Hermes Agent Applications
**Date:** 2026-06-24

## Key Examples
@HardianNazief highlighted the new animated pet feature in Hermes Agent, where a sprite in the GUI or TUI reacts in real-time to different agent states including idle, running a tool, thinking, waiting, finishing, and failing. The system includes nearly 3000 pets available through a “petdex” gallery, with users able to submit their own custom sprites. This addition was announced around June 24 and ties directly into making the agent experience more engaging and state-aware during long-running workflows. The feature builds on the core Hermes Agent from Nous Research, turning abstract agent operations into visible, reactive feedback loops that help users monitor progress without constant manual checking.

@WesRoth discussed the new /learn feature released on June 23, which allows users to feed entire directories of source material such as code, API docs, manuals, PDFs, and configs directly into the agent. The agent then automatically distills this material into verifiable, reusable “skills” that can be applied in future sessions. This capability has driven massive growth in the skill library and is frequently cited as a core advantage of the Hermes ecosystem, enabling persistent knowledge capture that compounds over time rather than resetting with each conversation.

@HerissonTemich compared Hermes Agent’s growth trajectory against OpenClaw over the April to June 2026 period, noting Hermes’s explosive gains in skills created, token throughput, and GitHub metrics including stars, forks, and contributors. While OpenClaw maintains a lead in absolute ecosystem size, Hermes is closing the gap rapidly through its self-improving skill loop that allows agents to build and refine capabilities autonomously. This positions Hermes as a practical implementation of persistent, asynchronous, organization-wide agent systems that Andrej Karpathy and others have discussed in broader AI infrastructure conversations.

## Insights
The combination of real-time state visualization through animated pets and automated skill distillation from raw source material creates a feedback loop where agents become both more monitorable and more knowledgeable over repeated use. This addresses a common friction in agentic systems where users lose visibility into what the agent is doing during complex, multi-step tasks. The pet system in particular turns opaque tool calls and reasoning steps into intuitive visual cues, potentially reducing the cognitive load for users managing multiple concurrent agents.

Hermes’s rapid skill library expansion through the /learn mechanism suggests that the long-term value of these agents lies less in the base model and more in the accumulated, verifiable domain knowledge captured from user-provided materials. This shifts the competitive dynamic away from raw model performance toward ecosystem lock-in via personalized skills that are difficult for competitors to replicate without the same user data and workflows.

## Notable Opinions
Users describe Hermes as delivering on the vision of “persistent, asynchronous, org-wide agent” systems, with @lucas_montano noting its practical application for daily research, personal workflows, and long-term memory combined with skill development that yields significant token and time savings.
