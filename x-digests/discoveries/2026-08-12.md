Combines high-level features (type inference, pattern matching, generics, traits, async/await) with low-level control (manual memory + RAII, 100% C ABI compatibility). Ships with compiler, LSP, REPL, and editor plugins.  
  Why interesting: Real design philosophy bridging high-level ergonomics and low-level control without losing C interoperability — worth understanding the transpilation approach and tradeoffs.  
  Link: https://github.com/zenc-lang/zenc  
  Suggested next step: Clone the repo, read the README and any design docs, attempt to build and transpile a small example program.
