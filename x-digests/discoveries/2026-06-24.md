# Discoveries — 2026-06-24

## Investigate
- **BitNet.cpp (Microsoft)**: Official open-source framework for 1.58-bit (ternary weight) models. Enables running up to 100B-scale models at 5–7 tokens/s on regular x86 CPUs without GPU, with ~6x speed and dramatically lower energy use. Models appearing on Hugging Face. Strong candidate for efficient local inference experiments.  
  Link: https://github.com/microsoft/BitNet (inferred from announcements)  
  Suggested next step: Clone repo, test inference on a sample model, compare tokens/s and memory vs standard quantization.

- **Obsidian + Claude "LLM Wiki / Second Brain" pattern**: Persistent long-term memory via linked markdown files (CLAUDE.md, project folders, structured Inputs/Process/Outputs/Feedback). Uses Local REST API plugin + MCP for auto read/write. Massive cost optimization by avoiding repeated context ingestion; model-agnostic and improves over time.  
  Suggested next step: Set up a minimal vault with CLAUDE.md and one project folder; test loading scoped context in Claude Desktop/Code.

- **Dynamic ToolSearch meta-tool pattern**: Instead of dumping 20–100 tool schemas into context (exploding prompt size), expose a meta-tool that lets the agent reason about needed tools then dynamically load only relevant definitions at runtime. Seen in Claude Agent SDK and similar frameworks.  
  Suggested next step: Prototype a simple ToolSearch implementation in a small agent script or review Claude SDK examples.

- **PrintingPress.dev (ppressdev) library + CLI suite**: One binary providing 16+ powerful CLIs (Cloudflare, 1Password, xAI, Vercel, etc.) that also work inside AI coding agents (Claude Code, Codex). Recent major expansion with community contributions.  
  Link: https://printingpress.dev (inferred)  
  Suggested next step: Install the binary, test 2–3 CLIs in terminal and inside an agent session.

- **Model fan-out + synthesize pipelines**: Scripts that send the same prompt to multiple frontier models in parallel, dump outputs (e.g. to Obsidian), then use a final model to synthesize. Recursive variants claimed to approximate higher intelligence.  
  Suggested next step: Build a small shell/Python script for 3-model fan-out + synthesis on a research task; measure output quality vs single-model baseline.
