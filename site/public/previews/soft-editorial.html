Topic 01

AI in Design & Creativity

Key Examples

@itsalexvacca shared that their design team replaced traditional tools with Claude Code in the terminal + Figma MCP. A non-technical designer now works almost entirely from the command line. Human brings taste and direction, AI handles layout, structure, copy, and grunt work. Result: 5× output, 50+ pieces shipped in one month, some reaching 90K+ impressions. They give away their full stack — Figma MCP setup files and cheat sheets — for free. x.com/itsalexvacca/status/2057457399427125290
@designtako is leading the conversation on CLAUDE.md / DESIGN.md files — a central Markdown brain that Claude reads on every run, encoding typography, spacing, color rules, component standards, and taste principles. They are sharing free collections of 2,000+ real DESIGN.md files extracted from top products, letting anyone bootstrap a production-grade design system for their agent. x.com/designtako/status/2059205402202677657
@jacobtechtavern demonstrated an agentic end-to-end pipeline: Linear ticket → Figma MCP scrapes specs and assets → implementation → flowdeck CLI screenshots for visual verification → PR creation with proof attached. The kicker: developers sometimes never open Xcode. The agent handles the full loop. x.com/jacobtechtavern/status/2058145169929609508
"Taste principles pulled from thousands of top-product examples, encoded into CLAUDE.md, are what separate generic AI output from production-quality design."
— @designtako

Insights

The community has largely moved past dedicated "Claude Design" interfaces. Terminal-first, agentic pipelines are the new standard. MCPs are the true breakthrough — they let Claude pull live context from Figma, Linear, and Mobbin, transforming it from a generic text generator into a connected agent that understands your actual design system.
Well-configured CLAUDE.md files and MCPs now matter more than raw model power. Taste stays human. Everything else is becoming a terminal pipeline.

Topic 02

Niche & Boring Businesses

Key Examples

@AlfieJCarter broke down 31 Anthropic Claude skills mapped to real small business workflows across finance, sales, HR, marketing, and reporting. Key skills include Business Pulse (dashboard), Invoice Chase (auto-follows overdue payments), Friday Brief (KPIs), Job Post Builder, Close Month, and Tax Prep. The package includes a 12-connector setup guide with explicit permission hygiene. The pitch: a 15-minute daily Cowork routine that returns hours of owner time. x.com/AlfieJCarter/status/2057848330902745536
@polsia is shipping narrow vertical AI agents for local service businesses — HVAC, roofing, plumbing, dental. ResponseIQ handles 24/7 lead response in under 60 seconds, plus missed-call text-back, appointment booking, and Google review drafting. CapCall is a dedicated AI phone receptionist. FieldFlow handles back-office for trades. One dental practice was losing $100,000+ per year to missed calls — a single extra booked job covers the agent's cost. x.com/polsia/status/2059119330215022685

Insights

The highest-leverage automations for local/service businesses converge on a single pattern: fast lead response, missed-call handling, and appointment booking. Everything else is secondary. Most successful implementations start with 4–7 well-wired skills rather than trying all 31.

Topic 03

Hermes Agent Applications

Key Examples

Users are deploying on-chain autonomous trading agents via ARCANA on Arc testnet. Deposit testnet USDC into a vault, select a strategy, and Hermes manages perpetual futures positions autonomously — reading market data, updating oracles, opening and closing positions, handling stop-loss and take-profit. Three personality-based agents run simultaneously: Apollo (conservative, long-only), Atlas (balanced), and Ares (aggressive, high-leverage, momentum-driven). x.com/arcanaweb/status/2059179802372837629

Insights

Hermes is being used as persistent infrastructure — an "operating layer" — rather than a single assistant. The strongest workflows combine human approval gates with long-running automation, suggesting trust and control are still bigger barriers than raw capability.
