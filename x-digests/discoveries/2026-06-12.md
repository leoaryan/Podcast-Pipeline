## Investigate
- **Telegram + local LLM private context bridge** (simrat11exp): Phone messages trigger a local Mac script that queries Claude/Gemini/Deepseek against laptop documents and replies with voice notes via open-source TTS. Clever low-cost integration for on-the-go private RAG without cloud exposure. Link: https://x.com/simrat11exp/status/2064753550094176645. Next step: Clone/reproduce the bot+script setup and test with personal docs.
- **SkillsGate**: Open-source platform for discovering, installing, organizing, and syncing AI agent skills across Claude Code, Cursor, Windsurf, Copilot, Codex CLI etc. Directly addresses tool fragmentation in agent workflows. GitHub: https://github.com/skillsgate/skillsgate. Next step: Install and evaluate skill sync across two environments.
- **ABBEL belief-state framework** (Berkeley AI): Replaces context summarization with supervised natural-language "belief states" + grading/penalties for long-horizon agents. +40% perf, 33% less memory; open-sourced. Strong practical pattern for agent memory. Link: https://x.com/i/status/2065156973008744568. Next step: Review the paper/code and test on a simple long-running agent task.
- **Mercury 2 diffusion LLM** (Inception AI via Baseten): Parallel token generation architecture delivering 1,000+ tokens/sec, ~90% cost savings and 82% lower latency vs sequential models. Architectural shift worth investigating for inference optimization. Link: https://x.com/volokuleshov/status/2065117276731482355. Next step: Check Baseten benchmarks and deployment docs.
- **Multi-agent code review pipeline** (HackenProof): Specialized agents per bug class (reentrancy, access control etc.) instead of monolithic prompts; same model + better structure improves results. Link: https://x.com/HackenProof/status/2065058040898781486. Next step: Implement a minimal version for a small codebase.
