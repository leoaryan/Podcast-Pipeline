### 1. 8-Layer Production Agent Architecture (elora_khatun)
**Source**: https://x.com/elora_khatun/status/2061630565972103214
**What was built**: Production-ready AI agent systems moving beyond prompt engineering.
**Step-by-step methodology**:
1. Define Purpose (use case, constraints, success metrics).
2. System Prompt Design (role, goals, guardrails as OS).
3. LLM Selection (match to task: GPT for tools, Claude for reasoning).
4. Tools & Integrations (APIs, DBs, custom tools).
5. Memory Systems (working, vector, episodic).
6. Orchestration (workflows, triggers, retries, multi-agent).
7. User Interface (chat, Slack, API, dashboard).
8. Testing & Evaluations (reliability, latency, hallucinations).
**Tool stack**: LangChain/LangGraph foundations, vector DBs (FAISS), custom tools.
**Architecture**: Layered systems design treating orchestration/memory/eval as core differentiators.
**Non-obvious insight**: AI Engineering in 2026 = Software Engineering + Prompting + Systems Design. Orchestration separates toys from production.
**Score**: Novelty 4, Actionability 5, Depth 5, Relevance 5 (Total 19/20). Directly applicable to Hermes agent extensions.
**What we can apply**: Adopt the 8-layer checklist for any new Hermes skill or pipeline.

### 2. Paul Iusztin’s 3-Phase Planning/Implement/Review Agent Swarm
**Source**: https://x.com/pauliusztin_/status/2068971198466195588
**What was built**: Open-sourced agent system for feature implementation.
**Step-by-step**:
- plan/: Human (or Product Architect agent) creates tasks, ADRs, glossary, research, critique.
- implement/: Swarm of SWE + Tester agents executes.
- review/: Multi-perspective review (product/code/architecture); failures spawn new tasks; includes CI and /self-improve.
**Tool stack**: Sub-agents, structured tasks/todo.md.
**Non-obvious insight**: Keep humans in highest-leverage planning; agents excel at execution/iteration.
**Score**: Novelty 4, Actionability 5, Depth 4, Relevance 5 (Total 18/20).
**What we can apply**: Integrate similar plan/implement/review loops into Hermes cron jobs or agent profiles.
