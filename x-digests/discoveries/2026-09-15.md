# Discoveries — 2026-09-15

## Investigate
- **LLMOS (Onchain AI Agent Framework)**: Framework for launching autonomous AI agents on Robinhood Chain in a single transaction. Each agent gets its own token, personality, chosen model (via OpenRouter), wallet, and access to a shared compute layer. Token trading fees fund a compute pool that pays for ongoing LLM inference, enabling self-sustaining agents that trade, allocate capital, own assets, and act autonomously. Positions as onchain evolution of frameworks like ElizaOS. First live experiment: @llmos_agent seeded with ~$50k in fees. 
  Why interesting: Novel economic model for funding and sustaining onchain AI agents. 
  Link: https://llmtokens.fun/agents (tweet: https://x.com/launchLLMs/status/2099645808089940091)
  Suggested next step: Explore the framework documentation, token mechanics, and how the compute layer integrates with agents.

- **Open-Generative-AI**: Self-hosted, open source desktop/web app aggregating 400+ models across 14 "studios" for image, video, audio, and voice generation. Fully local, MIT licensed, no content filters, watermarks, or subscriptions; supports commercial use. Aims to consolidate paid services like Midjourney, Runway, ElevenLabs, Suno into one interface.
  Why interesting: Comprehensive local alternative for generative workflows.
  GitHub: https://github.com/Anil-matcha/Open-Generative-AI
  Suggested next step: Clone the repo, review setup, and test model aggregation and local inference capabilities.

- **SDE (Scientific Discovery Evaluation) Framework (MIT)**: Framework for evaluating LLMs on real end-to-end scientific research tasks (hypothesis generation → simulation → iteration) across biology, chemistry, materials science, and physics, rather than static exam-style benchmarks. Emphasizes that scaling alone doesn't solve real discovery limitations.
  Why interesting: Practical approach to benchmarking AI for scientific discovery workflows.
  Link: https://x.com/KanikaBK/status/2099512753488859645
  Suggested next step: Locate the associated paper or repository and examine the evaluation methodology and benchmarks.

- **Git AI**: Open-source tool for analyzing how coding agents contribute to codebases (runs at scale in many companies). Recently acquired by OpenAI's Codex team with plans to keep it open source.
  Why interesting: Insights into measuring and understanding AI coding agent impact on real codebases.
  Link: https://x.com/ivanburazin/status/2099509476332113922
  Suggested next step: Find the GitHub repository and explore its analysis features and integration patterns.
