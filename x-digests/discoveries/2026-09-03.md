# Discoveries — 2026-09-03

## Investigate
- **NVIDIA NOOA (OOP for AI Agents)**: Framework that models agents as regular Python classes where methods are actions filled by LLMs at runtime (docstrings become prompts, return types enforce contracts). Handles large data structures efficiently by keeping them in session memory with previews only sent to the model. Strong SWE-bench results with fewer tokens/calls. Why interesting: Turns agent development into familiar software engineering with predictable behavior and cost savings. X post: https://x.com/DailyDoseOfDS_/status/2094719424242856390. Suggested next: Explore the GitHub repo or implementation details; experiment with defining a simple agent class.
- **Superlinked Inference Engine (SIE)**: Single-process engine to run 85+ models (embedders, rerankers, LLMs, etc.) on one GPU with LRU-based dynamic loading/eviction. Supports LangChain/LlamaIndex integrations and various call types. Why interesting: Solves idle GPU waste and high costs in multi-model agent pipelines; practical infrastructure for production agentic systems. X post: https://x.com/_avichawla/status/2094678972344958984. Suggested next: Review project docs or source for setup and benchmarks.
- **NVIDIA Switchyard (LLM Routing Proxy)**: Open-source (Apache 2.0) Rust-based proxy/library for LLM request routing with types like passthrough, random, llm_classifier, and stage_router (uses tool results to skip classifiers). Features session affinity, sub-ms overhead, streaming support, and compatibility with OpenAI/Anthropic/vLLM/Ollama etc. Why interesting: Advanced, low-overhead production pattern for model routing, cost optimization, and orchestration beyond simple gateways. X post: https://x.com/Marktechpost/status/2095213728086306957. Suggested next: Clone the repo, test routing strategies with sample providers.
- **Forward Deployed Engineer AI Integration Playbook**: Detailed list of 12 real-world projects for bridging AI with enterprise/legacy systems (e.g., bi-directional legacy DB sync with conflict resolution, PII redaction proxy, air-gapped one-click K8s deploy, custom MCP server for ERPs like SAP, AI fallback gateways, compliance auditors). Why interesting: Concrete, unconventional integration patterns and scripts that address messy production realities (security, compliance, reliability) often missing from tutorials. X post: https://x.com/suraj_sharma14/status/2095127540222603432. Suggested next: Read the full thread for project ideas; prototype a small component like the PII proxy or fallback gateway.
- **Bifrost LLM Gateway**: Apache 2.0 open-source gateway providing unified OpenAI-compatible API, routing, load balancing, fallbacks, guardrails, and observability. Why interesting: Complements routing tools with a full production stack for managing multiple LLM providers reliably. X post: https://x.com/alvinunreal/status/2094901589240668415. Suggested next: Check the GitHub repository and try integrating with existing setups.
